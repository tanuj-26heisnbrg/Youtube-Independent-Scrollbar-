Privacy Policy

Last updated: November 5, 2026

This Privacy Policy explains how the Independent Scrollbar Chrome Extension handles user information.

1. About the Extension

Independent Scrollbar is a Chrome browser extension that allows users to independently scroll through the recommendations sidebar on YouTube watch pages without affecting the main video page.

2. Information Collection

Independent Scrollbar does not collect, sell, or transmit personally identifiable information, browsing history, or personal user data to external servers or third parties.

3. Local Storage

The extension uses Chrome's storage functionality to save the user's preferred on/off setting. This information is stored locally through the Chrome extension storage API and is used only to maintain the user's preferences.

4. Website Access

The extension accesses YouTube watch pages solely to provide its independent scrolling functionality for the recommendations sidebar. It does not collect or transmit YouTube page content.

5. Third-Party Services

The extension does not use third-party analytics, advertising, or tracking services.

6. Data Sharing

We do not sell, rent, or share user information with third parties. The extension does not operate a backend server or maintain a database of user information.

7. Data Security

The extension is designed to operate locally within the user's browser. Its preference settings are stored using Chrome's built-in storage functionality.

8. Changes to This Privacy Policy

This Privacy Policy may be updated when necessary. Any changes will be published on this page.

9. Contact

For questions or concerns regarding this Privacy Policy, please contact the developer through the support contact information provided on the Chrome Web Store listing.
